🐧 Hi coder 🐧!

Your computer has no desktop and no mouse to click: you talk to it by writing commands, like a wizard. ✨ You can't break anything serious — so explore fearlessly, try again, have fun!

🔑 Log in & shut down

At startup, the computer asks who you are:

fedora login: your-login # your username, then Enter Password: # your password, then Enter
A perfectly normal surprise 👀: when you type your password, nothing shows up (no stars, nothing at all!). That's on purpose so nobody can see it. Type it 'into the void' and press Enter — it works.

To shut down when you're done: press the power button briefly (never hold it!), or type sudo systemctl poweroff. To restart: sudo systemctl reboot.

⭐ Secret #1: the TAB key ↹

You do NOT need to type everything! Write the start of a word, press Tab ↹, and the computer completes it for you.
cd Mu ← Tab ↹ → cd Music/
🔼 Up arrow = last command.   🧹 clear = clears the screen.   ❓ man name = help (q to quit).

⌨️ The special signs (| ~ \ { } …)

For commands and code, some signs are 'hidden' on the keyboard — often with the AltGr key (right of the space bar). Ask an adult to show you, and write them down here so you never search again:

📥 Install programs & update

You can install any app that works in the console (browsers and desktops are blocked).

🔄 Update the whole computer (programs + system) — do it now and then, e.g. once a week:
sudo maj
It downloads the latest of everything and fixes bugs.

🔍 See what's running & stop a program

To see every running program (and how much of the computer they use), launch a 'monitor':

htop # colourful monitor (arrows to move, q to quit) btop # another one, even prettier! 📊

(htop and btop are already installed. Otherwise: pkg install htop btop.)

🎵 Your music

1) Tidy your music 📁

cd mkdir -p Music # create the Music folder cd Music mkdir Rock Rap Video-games # one sub-folder per style (if you like)

2) Download music ⬇️

Lots of music is free and libre (you're allowed to take it!). Ask an adult to help you find some, for example on archive.org, Free Music Archive or Jamendo.

To download in the console we use aria2c — it handles direct links, .torrent files and magnet links:

aria2c "https://.../song.mp3" # a direct link aria2c file.torrent # a torrent file aria2c "magnet:?xt=..." # a magnet link
Play fair ⚖️: take free / libre music, or music the family already owns. Downloading paid music without paying is not allowed — if in doubt, ask an adult.
Files arrive in the folder you're in. Then tidy them away:
mv *.mp3 ~/Music/Rock/

3) Listen 🔊

cd ~/Music/Rock mpg123 song.mp3 # a single song mpg123 *.mp3 # the whole folder, one after another mpg123 -C *.mp3 # with keys: space = pause, q = quit

4) Make a playlist 🎶

A playlist is just a text file with one song per line. Create it:

cd ~/Music micro myplaylist.txt

Write the paths of your songs inside (Ctrl+S to save, Ctrl+Q to quit):

Rock/song1.mp3
Rap/song2.mp3
Video-games/zelda.mp3

Then play your playlist:

mpg123 -@ myplaylist.txt # plays the whole playlist mpg123 -C -@ myplaylist.txt # same, with space = pause, q = quit
✦ Pro tip: put the line mpg123 -C -@ ~/Music/myplaylist.txt in a small file play.sh, make it executable (chmod +x play.sh), and launch all your music with ./play.sh!

😵 When it doesn't work (that's normal!)

Everyone makes mistakes, even pros. Here are the messages you'll see often:

The 3 classic traps:

  • ␣ Spaces count: for a folder 'My Games', write cd "My Games" (with the quotes).

🐍 Challenge 0 — Code Snake (start here!)

We use curses (to draw in the terminal). micro serpent.py

Step 1
Open a curses window that waits for a key: 
import curses
def main(stdscr):
    stdscr.addstr(5, 5, "Salut ! Appuie sur une touche.")
    stdscr.getch()
curses.wrapper(main)
🔍 What the code does:
  • curses.wrapper(main) sets up the 'game' screen then runs main.
  • addstr(row, col, text) writes at an exact spot.
  • getch() waits for you to press a key.
▶ python3 serpent.py
→ a message, then a key to exit.
Step 2
A dot # that moves with the arrow keys (q to quit): 
import curses
def main(stdscr):
    curses.curs_set(0); stdscr.nodelay(True); stdscr.timeout(120)
    h, w = stdscr.getmaxyx()
    y, x = h//2, w//2
    dy, dx = 0, 1
    while True:
        k = stdscr.getch()
        if k == ord('q'): break
        if k == curses.KEY_UP: dy, dx = -1, 0
        elif k == curses.KEY_DOWN: dy, dx = 1, 0
        elif k == curses.KEY_LEFT: dy, dx = 0, -1
        elif k == curses.KEY_RIGHT: dy, dx = 0, 1
        y = max(0, min(h-1, y+dy)); x = max(0, min(w-2, x+dx))
        stdscr.clear(); stdscr.addstr(y, x, "#"); stdscr.refresh()
curses.wrapper(main)
🔍 What the code does:
  • nodelay(True) + timeout(120): the game doesn't wait, it moves by itself every 120 ms.
  • The arrow keys change the direction dy, dx.
  • y += dy moves the dot; clear() wipes before redrawing; max/min keep it on screen.
▶ python3 serpent.py
(don't forget Ctrl+S first!) → you drive a dot!
Step 3
A real snake: a list of segments that moves (we add a head, remove the tail): 
import curses
def main(stdscr):
    curses.curs_set(0); stdscr.nodelay(True); stdscr.timeout(120)
    h, w = stdscr.getmaxyx()
    serpent = [(h//2, w//2 - i) for i in range(3)]    # 3 segments
    dy, dx = 0, 1
    while True:
        k = stdscr.getch()
        if k == ord('q'): break
        if k == curses.KEY_UP and dy == 0: dy, dx = -1, 0
        elif k == curses.KEY_DOWN and dy == 0: dy, dx = 1, 0
        elif k == curses.KEY_LEFT and dx == 0: dy, dx = 0, -1
        elif k == curses.KEY_RIGHT and dx == 0: dy, dx = 0, 1
        ty, tx = serpent[0][0]+dy, serpent[0][1]+dx
        serpent.insert(0, (ty, tx))      # nouvelle tete
        serpent.pop()                    # on enleve la queue
        try:
            stdscr.clear()
            for (yy, xx) in serpent: stdscr.addstr(yy, xx, "#")
        except curses.error: pass
        stdscr.refresh()
curses.wrapper(main)
🔍 What the code does:
  • serpent = a list of cells (the head is first).
  • insert(0, …) adds a new head, pop() removes the tail → it moves.
  • and dy == 0 stops it from turning back on itself.
▶ python3 serpent.py
(save first: Ctrl+S) → the snake glides on its own.
Step 4
The apple * and the score: when it eats, it grows. 
import curses, random
def main(stdscr):
    curses.curs_set(0); stdscr.nodelay(True); stdscr.timeout(120)
    h, w = stdscr.getmaxyx()
    serpent = [(h//2, w//2 - i) for i in range(3)]
    dy, dx = 0, 1
    pomme = (random.randint(1, h-2), random.randint(1, w-2))
    score = 0
    while True:
        k = stdscr.getch()
        if k == ord('q'): break
        if k == curses.KEY_UP and dy == 0: dy, dx = -1, 0
        elif k == curses.KEY_DOWN and dy == 0: dy, dx = 1, 0
        elif k == curses.KEY_LEFT and dx == 0: dy, dx = 0, -1
        elif k == curses.KEY_RIGHT and dx == 0: dy, dx = 0, 1
        ty, tx = serpent[0][0]+dy, serpent[0][1]+dx
        serpent.insert(0, (ty, tx))
        if (ty, tx) == pomme:                 # il mange -> il grandit
            score += 1
            pomme = (random.randint(1, h-2), random.randint(1, w-2))
        else:
            serpent.pop()
        try:
            stdscr.clear(); stdscr.border()
            stdscr.addstr(0, 2, f" Score: {score} ")
            stdscr.addstr(pomme[0], pomme[1], "*")
            for (yy, xx) in serpent: stdscr.addstr(yy, xx, "#")
        except curses.error: pass
        stdscr.refresh()
curses.wrapper(main)
🔍 What the code does:
  • random.randint places the apple at random.
  • If the head reaches the apple: +1 score and we do NOT remove the tail → the snake grows.
  • border() draws the frame, the score shows at the top.
▶ python3 serpent.py
(save first: Ctrl+S) → eat the apples, the snake gets longer.
Step 5 — game over
We add 'Game Over' if you hit a wall or your own body: 
import curses, random
def main(stdscr):
    curses.curs_set(0); stdscr.nodelay(True); stdscr.timeout(120)
    h, w = stdscr.getmaxyx()
    serpent = [(h//2, w//2 - i) for i in range(3)]
    dy, dx = 0, 1
    pomme = (random.randint(1, h-2), random.randint(1, w-2))
    score = 0
    while True:
        k = stdscr.getch()
        if k == ord('q'): break
        if k == curses.KEY_UP and dy == 0: dy, dx = -1, 0
        elif k == curses.KEY_DOWN and dy == 0: dy, dx = 1, 0
        elif k == curses.KEY_LEFT and dx == 0: dy, dx = 0, -1
        elif k == curses.KEY_RIGHT and dx == 0: dy, dx = 0, 1
        ty, tx = serpent[0][0]+dy, serpent[0][1]+dx
        # PERDU si on touche un mur ou son propre corps
        if ty in (0, h-1) or tx in (0, w-1) or (ty, tx) in serpent:
            break
        serpent.insert(0, (ty, tx))
        if (ty, tx) == pomme:
            score += 1
            pomme = (random.randint(1, h-2), random.randint(1, w-2))
        else:
            serpent.pop()
        stdscr.clear(); stdscr.border()
        stdscr.addstr(0, 2, f" Score: {score}  (q pour quitter) ")
        stdscr.addstr(pomme[0], pomme[1], "*")
        for (yy, xx) in serpent: stdscr.addstr(yy, xx, "#")
        stdscr.refresh()
    stdscr.nodelay(False); stdscr.clear()
    stdscr.addstr(h//2, max(0, w//2-7), f"Perdu ! Score {score}")
    stdscr.refresh(); stdscr.getch()
curses.wrapper(main)
🔍 What the code does:
  • if ty in (0, h-1) … checks if you hit a wall or your own body → break (end).
  • After the loop, we show 'Game over' and wait for a key.
▶ python3 serpent.py
→ the full game! 🎉

🌈 Challenge 1 — A 'plasma' demo

The demoscene is the art of programming beautiful animations. We start from scratch and build step by step. Create the file: micro plasma.py

Step 1
Show coloured squares. The secret code \033[48;5;Nm = 'background colour #N'. 
print("\033[48;5;201m        \033[0m")   # un carre ROSE
print("\033[48;5;46m        \033[0m")    # un carre VERT
print("\033[48;5;21m        \033[0m")    # un carre BLEU
🔍 What the code does:
  • print(...) shows something on screen.
  • \033[48;5;201m = secret code 'background colour #201'.
  • \033[0m resets the colour (otherwise everything stays coloured).
▶ python3 plasma.py
→ you see 3 coloured squares.
Step 2
A loop to make a gradient line (one colour per column): 
ligne = ""
for x in range(30):
    ligne += f"\033[48;5;{16 + x}m "     # une couleur differente a chaque pas
print(ligne + "\033[0m")
🔍 What the code does:
  • for x in range(30) repeats 30 times (x = 0,1,2…29).
  • Each turn we add a coloured space; colour 16+x changes every column.
  • We print the whole line at the end.
▶ python3 plasma.py
→ a lovely rainbow line.
Step 3
Two nested loops = a whole screen (rows × columns): 
for y in range(20):              # 20 lignes
    ligne = ""
    for x in range(50):          # 50 colonnes
        couleur = 16 + (x + y) % 200
        ligne += f"\033[48;5;{couleur}m "
    print(ligne + "\033[0m")
🔍 What the code does:
  • for y walks the rows, for x the columns: a grid!
  • (x+y) % 200 gives a number that changes with position → a diagonal gradient.
  • % = the remainder of a division (here, 0 to 199).
▶
→ a diagonal pattern.
Step 4
We replace the colour maths with sines (waves!): 
import math
for y in range(20):
    ligne = ""
    for x in range(50):
        v = math.sin(x * 0.3) + math.sin(y * 0.3)   # des vagues !
        couleur = 16 + int((v + 2) / 4 * 200)
        ligne += f"\033[48;5;{couleur}m "
    print(ligne + "\033[0m")
🔍 What the code does:
  • math.sin(...) is a 'wave' function that goes up and down.
  • We add a wave on x and a wave on y → ripples.
  • int(...) rounds to a whole number to pick the colour.
▶
→ soft waves of colour.
Step 5 — animation!
We put it all in a while loop with time t moving forward: 
import math, time, shutil
cols, rows = shutil.get_terminal_size(); rows -= 1
print("\033[?25l", end="")              # cache le curseur
t = 0
try:
    while True:
        print("\033[H", end="")         # curseur tout en haut
        for y in range(rows):
            ligne = ""
            for x in range(cols):
                v = math.sin(x*0.1+t) + math.sin(y*0.1-t) + math.sin((x+y)*0.08+t)
                couleur = 16 + int((v+3)/6*215)
                ligne += f"\033[48;5;{couleur}m "
            print(ligne + "\033[0m")
        t += 0.2                         # le temps avance -> ca bouge
        time.sleep(0.05)
except KeyboardInterrupt:
    print("\033[0m\033[?25h")            # remontre le curseur
🔍 What the code does:
  • while True: = endless loop: the heart of the animation.
  • \033[H moves the cursor back to the top to redraw on top → animated effect.
  • t += 0.2 moves 'time' forward → the waves travel; time.sleep waits between two frames.
  • except KeyboardInterrupt = quit cleanly with Ctrl+C.
▶ python3 plasma.py
(Ctrl+C to stop) → it moves! 🎉

import numpy as np, sounddevice as sd

duree = 0.5

  • sd.play plays the sound, sd.wait waits until it finishes.
▶ python3 musique.py
→ you hear an 'A'! 🔊
Step 2
We tidy that into a function note() and play 3 notes: 
import numpy as np, sounddevice as sd
SR = 44100
def note(freq, duree=0.4):              # une fonction qui fabrique une note
    t = np.linspace(0, duree, int(SR*duree), False)
    return 0.3 * np.sin(2*np.pi*freq*t)
son = np.concatenate([note(262), note(330), note(392)])   # do, mi, sol
sd.play(son.astype(np.float32), SR); sd.wait()
🔍 What the code does:
  • def note(freq) creates a reusable function that builds a note.
  • np.concatenate([...]) joins several notes end to end.
  • 262, 330, 392 = the frequencies of C, E, G.
▶
→ C, E, G one after another.
Step 3 — your melody
A dictionary of notes + a list = a real score: 
import numpy as np, sounddevice as sd
SR = 44100
def note(freq, duree=0.4):
    t = np.linspace(0, duree, int(SR*duree), False)
    return 0.3 * np.sin(2*np.pi*freq*t)
notes = {"do":262,"re":294,"mi":330,"fa":349,"sol":392,"la":440,"si":494}
melodie = ["do","re","mi","fa","sol","la","si"]      # <- ta partition !
son = np.concatenate([note(notes[n]) for n in melodie]).astype(np.float32)
sd.play(son, SR); sd.wait()
print("A toi de changer la melodie !")
🔍 What the code does:
  • notes = {...} = a dictionary: each note name → its frequency.
  • melodie = [...] = the list of notes to play, in order.
  • [note(notes[n]) for n in melodie] builds the sound of each note in the list.
▶ python3 musique.py

🧱 Challenge 3 — Code a Breakout

micro casse-brique.py

Step 1
A paddle ==== at the bottom, moving left/right: 
import curses
def main(stdscr):
    curses.curs_set(0); stdscr.nodelay(True); stdscr.timeout(60)
    h, w = stdscr.getmaxyx()
    rx, rw = w//2, 8                     # raquette : position, largeur
    while True:
        k = stdscr.getch()
        if k == ord('q'): break
        if k == curses.KEY_LEFT: rx = max(1, rx-2)
        elif k == curses.KEY_RIGHT: rx = min(w-rw-1, rx+2)
        stdscr.clear(); stdscr.border()
        stdscr.addstr(h-2, rx, "=" * rw)
        stdscr.refresh()
curses.wrapper(main)
🔍 What the code does:
  • rx = paddle position, rw = its width.
  • The arrows change rx; max/min keep it on screen.
  • "=" * rw draws the paddle (rw times the = sign).
▶
→ you move the paddle.
Step 2
The ball O bouncing off the walls and the paddle (and you lose at the bottom): 
import curses
def main(stdscr):
    curses.curs_set(0); stdscr.nodelay(True); stdscr.timeout(60)
    h, w = stdscr.getmaxyx()
    rx, rw = w//2, 8
    bx, by, ddx, ddy = w//2, h-3, 1, -1     # balle : position + direction
    while True:
        k = stdscr.getch()
        if k == ord('q'): break
        if k == curses.KEY_LEFT: rx = max(1, rx-2)
        elif k == curses.KEY_RIGHT: rx = min(w-rw-1, rx+2)
        bx += ddx; by += ddy
        if bx <= 1 or bx >= w-2: ddx = -ddx       # rebond murs gauche/droite
        if by <= 1: ddy = -ddy                    # rebond plafond
        if by == h-2 and rx <= bx <= rx+rw: ddy = -1   # rebond raquette
        if by >= h-1: break                       # balle perdue
        try:
            stdscr.clear(); stdscr.border()
            stdscr.addstr(h-2, rx, "=" * rw)
            stdscr.addch(by, bx, "O")
        except curses.error: pass
        stdscr.refresh()
    stdscr.nodelay(False)
    stdscr.addstr(h//2, max(0, w//2-4), "Perdu !"); stdscr.getch()
curses.wrapper(main)
🔍 What the code does:

import curses
def main(stdscr):
    curses.curs_set(0); stdscr.nodelay(True); stdscr.timeout(60)
    h, w = stdscr.getmaxyx()
    briques = set()
    for by in range(2, 5):
        for bx in range(2, w-3, 4): briques.add((by, bx))
    rx, rw = w//2, 8
    bx, by, ddx, ddy = w//2, h-3, 1, -1
    score = 0
    while True:
        k = stdscr.getch()
        if k == ord('q'): break
        if k == curses.KEY_LEFT: rx = max(1, rx-2)
        elif k == curses.KEY_RIGHT: rx = min(w-rw-1, rx+2)
        bx += ddx; by += ddy
        if bx <= 1 or bx >= w-2: ddx = -ddx
        if by <= 1: ddy = -ddy
        if by == h-2 and rx <= bx <= rx+rw: ddy = -1
        if by >= h-1: break
        for cible in ((by, bx), (by, bx-1)):       # brique touchee ?
            if cible in briques:
                briques.discard(cible); ddy = -ddy; score += 1; break
        try:
            stdscr.clear(); stdscr.border()
            stdscr.addstr(0, 2, f" Score: {score}  briques: {len(briques)} (q) ")
            for (yy, xx) in briques: stdscr.addstr(yy, xx, "[]")
            stdscr.addstr(h-2, rx, "=" * rw)
            stdscr.addch(by, bx, "O")
        except curses.error: pass
        if not briques:
            stdscr.addstr(h//2, max(0, w//2-4), "GAGNE !"); stdscr.refresh(); break
        stdscr.refresh()
    stdscr.nodelay(False); stdscr.getch()
curses.wrapper(main)

Step 2 — the magic
We 'smooth' it with a cellular automaton, repeated 5 times → it carves caverns: 
import random
L, H = 50, 18
grille = [[1 if random.random() < 0.45 else 0 for _ in range(L)] for _ in range(H)]
for _ in range(5):                          # 5 passes de lissage
    neuf = [[0]*L for _ in range(H)]
    for y in range(H):
        for x in range(L):
            murs = sum(
                not (0 <= y+dy < H and 0 <= x+dx < L) or grille[y+dy][x+dx] == 1
                for dy in (-1,0,1) for dx in (-1,0,1))
            neuf[y][x] = 1 if murs >= 5 else 0
    grille = neuf
for ligne in grille:
    print("".join("#" if c else " " for c in ligne))
🔍 What the code does:
  • For each cell, we count its rock neighbours.
  • 5 rock-neighbours or more → the cell becomes rock, otherwise it becomes empty.
  • Repeated 5 times, it 'carves' real caverns: a cellular automaton!
▶ python3 grotte.py
→ real caves appear! 🌀
Step 3 — explore it

import curses, random
L, H = 50, 18
def generer():
    g = [[1 if random.random() < 0.45 else 0 for _ in range(L)] for _ in range(H)]
    for _ in range(5):
        n = [[0]*L for _ in range(H)]
        for y in range(H):
            for x in range(L):
                murs = sum(not (0 <= y+dy < H and 0 <= x+dx < L) or g[y+dy][x+dx] == 1
                           for dy in (-1,0,1) for dx in (-1,0,1))
                n[y][x] = 1 if murs >= 5 else 0
        g = n
    return g
def main(stdscr):
    curses.curs_set(0); stdscr.nodelay(True); stdscr.timeout(120)
    g = generer()
    py, px = 1, 1
    for y in range(H):                       # trouve une case vide pour demarrer
        for x in range(L):
            if g[y][x] == 0: py, px = y, x; break
        else: continue
        break
    while True:
        k = stdscr.getch()
        if k == ord('q'): break
        ny, nx = py, px
        if k == curses.KEY_UP: ny -= 1
        elif k == curses.KEY_DOWN: ny += 1
        elif k == curses.KEY_LEFT: nx -= 1
        elif k == curses.KEY_RIGHT: nx += 1
        if 0 <= ny < H and 0 <= nx < L and g[ny][nx] == 0:
            py, px = ny, nx
        try:
            stdscr.clear()
            for y, row in enumerate(g):
                stdscr.addstr(y, 0, "".join("#" if c else " " for c in row))
            stdscr.addch(py, px, '@')
            stdscr.addstr(H, 0, "Explore ta grotte !  (q pour quitter)")
        except curses.error: pass
        stdscr.refresh()
curses.wrapper(main)
🔍 What the code does:
  • generer() builds a new cave every run.
  • We look for an empty cell to place the explorer @.
  • We only move if the destination cell is empty (not rock).
