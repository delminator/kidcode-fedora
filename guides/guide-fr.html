🐧 Salut codeuse / codeur 🐧 !

Ton ordinateur n'a pas de bureau ni de souris à cliquer : tu lui parles en écrivant des commandes, comme un magicien. ✨ Tu ne peux rien casser de grave — alors explore sans peur, recommence, amuse-toi !

🔑 Se connecter & éteindre

Au démarrage, l'ordi te demande qui tu es :

fedora login: ton-compte # ton identifiant, puis Entrée Password: # ton mot de passe, puis Entrée
Surprise toute normale 👀 : quand tu tapes ton mot de passe, rien ne s'affiche (pas d'étoiles, rien du tout !). C'est fait exprès pour que personne ne le voie. Tape-le « dans le vide » et appuie sur Entrée — ça marche.

Pour éteindre quand tu as fini : appuie brièvement sur le bouton power (ne le tiens surtout pas appuyé !), ou tape sudo systemctl poweroff. Pour redémarrer : sudo systemctl reboot.

⭐ Le secret n°1 : la touche TAB ↹

Tu n'as PAS besoin de tout taper ! Écris le début d'un mot, appuie sur Tab ↹, et l'ordinateur complète tout seul.
cd Mu ← Tab ↹ → cd Musique/
🔼 Flèche Haut = dernière commande.   🧹 clear = nettoie l'écran.   ❓ man nom = aide (q pour sortir).

Pour les commandes et le code, certains signes sont « cachés » sur le clavier — souvent avec la touche AltGr (à droite de la barre d'espace). Demande à un adulte de te les montrer, et note-les ici pour ne plus chercher :

🎵 Ta musique

1) Range ta musique 📁

cd mkdir -p Musique # crée le dossier Musique cd Musique mkdir Rock Rap Jeux-video # un sous-dossier par style (si tu veux)

2) Télécharge de la musique ⬇️

Plein de musique est gratuite et libre (tu as le droit de la prendre !). Demande à un adulte de t'aider à en trouver, par exemple sur archive.org, Free Music Archive ou Jamendo.

Pour télécharger en console, on utilise aria2c — il gère les liens directs, les fichiers .torrent et les liens magnet :

aria2c "https://.../chanson.mp3" # un lien direct aria2c fichier.torrent # un fichier torrent aria2c "magnet:?xt=..." # un lien magnet
Sois réglo ⚖️ : prends de la musique libre / gratuite, ou que la famille possède déjà. Télécharger de la musique payante sans payer, c'est interdit — en cas de doute, demande à un adulte.
Les fichiers arrivent dans le dossier où tu es. Ensuite tu les ranges :
mv *.mp3 ~/Musique/Rock/

3) Écoute 🔊

cd ~/Musique/Rock mpg123 chanson.mp3 # une seule chanson mpg123 *.mp3 # tout le dossier, à la suite mpg123 -C *.mp3 # avec les touches : espace = pause, q = quitter

4) Fabrique une playlist 🎶

Une playlist, c'est juste un fichier texte avec une chanson par ligne. Crée-le :

cd ~/Musique micro maplaylist.txt

Écris dedans le chemin de tes chansons (Ctrl+S pour enregistrer, Ctrl+Q pour quitter) :

Rock/chanson1.mp3
Rap/chanson2.mp3
Jeux-video/zelda.mp3

Puis lance ta playlist :

mpg123 -@ maplaylist.txt # joue toute la playlist mpg123 -C -@ maplaylist.txt # pareil, avec espace = pause, q = quitter
✦ Astuce de pro : mets la ligne mpg123 -C -@ ~/Musique/maplaylist.txt dans un petit fichier jouer.sh, rends-le exécutable (chmod +x jouer.sh), et tu lances toute ta musique avec ./jouer.sh !

🐍 Défi 0 — Code le Serpent (on commence par là !)

On utilise curses (pour dessiner dans le terminal). micro serpent.py

Étape 1
Ouvrir une fenêtre curses qui attend une touche : 
import curses
def main(stdscr):

🔍 Ce que fait le code :
  • curses.wrapper(main) prépare l'écran « jeu » puis lance main.
  • addstr(ligne, colonne, texte) écrit à un endroit précis.
  • getch() attend que tu appuies sur une touche.
▶ python3 serpent.py
→ un message, puis une touche pour sortir.
Étape 2
Un point # qui bouge avec les flèches (q pour quitter) : 
import curses
def main(stdscr):
    curses.curs_set(0); stdscr.nodelay(True); stdscr.timeout(120)
    h, w = stdscr.getmaxyx()
    y, x = h//2, w//2
    dy, dx = 0, 1
    while True:
        k = stdscr.getch()
        if k == ord('q'): break
        if k == curses.KEY_UP: dy, dx = -1, 0
        elif k == curses.KEY_DOWN: dy, dx = 1, 0
        elif k == curses.KEY_LEFT: dy, dx = 0, -1
        elif k == curses.KEY_RIGHT: dy, dx = 0, 1
        y = max(0, min(h-1, y+dy)); x = max(0, min(w-2, x+dx))
        stdscr.clear(); stdscr.addstr(y, x, "#"); stdscr.refresh()
curses.wrapper(main)
🔍 Ce que fait le code :
  • nodelay(True) + timeout(120) : le jeu n'attend pas, il avance tout seul toutes les 120 ms.
  • Les flèches changent la direction dy, dx.
  • y += dy déplace le point ; clear() efface avant de redessiner ; max/min l'empêchent de sortir de l'écran.
▶ python3 serpent.py
(n'oublie pas Ctrl+S avant !) → tu pilotes un point !
Étape 3
Un vrai serpent : une liste de segments qui avance (on ajoute une tête, on retire la queue) : 
import curses
def main(stdscr):
    curses.curs_set(0); stdscr.nodelay(True); stdscr.timeout(120)
    h, w = stdscr.getmaxyx()
    serpent = [(h//2, w//2 - i) for i in range(3)]    # 3 segments
    dy, dx = 0, 1
    while True:
        k = stdscr.getch()
        if k == ord('q'): break
        if k == curses.KEY_UP and dy == 0: dy, dx = -1, 0
        elif k == curses.KEY_DOWN and dy == 0: dy, dx = 1, 0
        elif k == curses.KEY_LEFT and dx == 0: dy, dx = 0, -1
        elif k == curses.KEY_RIGHT and dx == 0: dy, dx = 0, 1
        ty, tx = serpent[0][0]+dy, serpent[0][1]+dx
        serpent.insert(0, (ty, tx))      # nouvelle tete
        serpent.pop()                    # on enleve la queue
        try:
            stdscr.clear()
            for (yy, xx) in serpent: stdscr.addstr(yy, xx, "#")
        except curses.error: pass
        stdscr.refresh()
curses.wrapper(main)
🔍 Ce que fait le code :
  • serpent = une liste de cases (la tête est en premier).
  • insert(0, …) ajoute une nouvelle tête, pop() enlève la queue → il avance.
  • and dy == 0 empêche de faire demi-tour sur soi-même.
▶ python3 serpent.py
(enregistre d'abord : Ctrl+S) → le serpent glisse tout seul.
Étape 4
La pomme * et le score : quand il mange, il grandit. 
import curses, random
def main(stdscr):
    curses.curs_set(0); stdscr.nodelay(True); stdscr.timeout(120)
    h, w = stdscr.getmaxyx()
    serpent = [(h//2, w//2 - i) for i in range(3)]
    dy, dx = 0, 1
    pomme = (random.randint(1, h-2), random.randint(1, w-2))
    score = 0
    while True:
        k = stdscr.getch()
        if k == ord('q'): break
        if k == curses.KEY_UP and dy == 0: dy, dx = -1, 0
        elif k == curses.KEY_DOWN and dy == 0: dy, dx = 1, 0
        elif k == curses.KEY_LEFT and dx == 0: dy, dx = 0, -1
        elif k == curses.KEY_RIGHT and dx == 0: dy, dx = 0, 1
        ty, tx = serpent[0][0]+dy, serpent[0][1]+dx
        serpent.insert(0, (ty, tx))
        if (ty, tx) == pomme:                 # il mange -> il grandit
            score += 1
            pomme = (random.randint(1, h-2), random.randint(1, w-2))
        else:
            serpent.pop()
        try:
            stdscr.clear(); stdscr.border()
            stdscr.addstr(0, 2, f" Score: {score} ")
            stdscr.addstr(pomme[0], pomme[1], "*")
            for (yy, xx) in serpent: stdscr.addstr(yy, xx, "#")
        except curses.error: pass
        stdscr.refresh()
curses.wrapper(main)
🔍 Ce que fait le code :
  • random.randint place la pomme au hasard.
  • Si la tête arrive sur la pomme : +1 au score et on NE retire PAS la queue → le serpent grandit.
  • border() dessine le cadre, le score s'affiche en haut.
▶ python3 serpent.py
(enregistre d'abord : Ctrl+S) → mange les pommes, le serpent s'allonge.
Étape 5 — la fin du jeu
On ajoute le « Game Over » si on touche un mur ou son corps : 
import curses, random
def main(stdscr):
    curses.curs_set(0); stdscr.nodelay(True); stdscr.timeout(120)
    h, w = stdscr.getmaxyx()
    serpent = [(h//2, w//2 - i) for i in range(3)]
    dy, dx = 0, 1
    pomme = (random.randint(1, h-2), random.randint(1, w-2))
    score = 0
    while True:
        k = stdscr.getch()
        if k == ord('q'): break
        if k == curses.KEY_UP and dy == 0: dy, dx = -1, 0
        elif k == curses.KEY_DOWN and dy == 0: dy, dx = 1, 0
        elif k == curses.KEY_LEFT and dx == 0: dy, dx = 0, -1
        elif k == curses.KEY_RIGHT and dx == 0: dy, dx = 0, 1
        ty, tx = serpent[0][0]+dy, serpent[0][1]+dx
        # PERDU si on touche un mur ou son propre corps
        if ty in (0, h-1) or tx in (0, w-1) or (ty, tx) in serpent:
            break
        serpent.insert(0, (ty, tx))
        if (ty, tx) == pomme:
            score += 1
            pomme = (random.randint(1, h-2), random.randint(1, w-2))
        else:
            serpent.pop()
        stdscr.clear(); stdscr.border()
        stdscr.addstr(0, 2, f" Score: {score}  (q pour quitter) ")
        stdscr.addstr(pomme[0], pomme[1], "*")
        for (yy, xx) in serpent: stdscr.addstr(yy, xx, "#")
        stdscr.refresh()
    stdscr.nodelay(False); stdscr.clear()
    stdscr.addstr(h//2, max(0, w//2-7), f"Perdu ! Score {score}")
    stdscr.refresh(); stdscr.getch()
curses.wrapper(main)
🔍 Ce que fait le code :
  • if ty in (0, h-1) … teste si on touche un mur ou son propre corps → break (fin).
  • Après la boucle, on affiche « Perdu ! » et on attend une touche.
▶ python3 serpent.py
→ le jeu complet ! 🎉
✦ À toi : change timeout(120) en timeout(60) → le serpent va 2× plus vite !

🌈 Défi 1 — Une démo « plasma »

La demoscene, c'est l'art de programmer de belles animations. On part de zéro et on construit pas à pas. Crée le fichier : micro plasma.py

Étape 1
Affiche des carrés de couleur. Le code secret \033[48;5;Nm = « fond couleur n° N ». 
print("\033[48;5;201m        \033[0m")   # un carre ROSE
print("\033[48;5;46m        \033[0m")    # un carre VERT
print("\033[48;5;21m        \033[0m")    # un carre BLEU
🔍 Ce que fait le code :
  • print(...) affiche quelque chose à l'écran.
  • \033[48;5;201m = code secret « fond couleur n°201 ».
  • \033[0m remet la couleur normale (sinon tout reste coloré).
▶ python3 plasma.py
→ tu vois 3 carrés de couleur.
Étape 2
Une boucle pour faire une ligne dégradée (une couleur par colonne) : 
ligne = ""
for x in range(30):
    ligne += f"\033[48;5;{16 + x}m "     # une couleur differente a chaque pas
print(ligne + "\033[0m")
🔍 Ce que fait le code :
  • for x in range(30) répète 30 fois (x = 0,1,2…29).
  • À chaque tour on ajoute un espace coloré ; la couleur 16+x change donc à chaque colonne.
  • On affiche la ligne entière à la fin.
▶ python3 plasma.py
→ une belle ligne arc-en-ciel.
Étape 3
Deux boucles imbriquées = tout un écran (lignes × colonnes) : 
for y in range(20):              # 20 lignes
    ligne = ""
    for x in range(50):          # 50 colonnes
        couleur = 16 + (x + y) % 200
        ligne += f"\033[48;5;{couleur}m "
    print(ligne + "\033[0m")
🔍 Ce que fait le code :
  • La boucle for y parcourt les lignes, for x les colonnes : une grille !
  • (x+y) % 200 donne un nombre qui change selon la position → un dégradé en diagonale.
  • % = le reste d'une division (ici, entre 0 et 199).
▶
→ un motif en diagonale.
Étape 4
On remplace le calcul de couleur par des sinus (des vagues !) : 
import math
for y in range(20):
    ligne = ""
    for x in range(50):
        v = math.sin(x * 0.3) + math.sin(y * 0.3)   # des vagues !
        couleur = 16 + int((v + 2) / 4 * 200)
        ligne += f"\033[48;5;{couleur}m "
    print(ligne + "\033[0m")
🔍 Ce que fait le code :
  • math.sin(...) est une fonction « vague » qui monte et descend.
  • On additionne une vague sur x et une sur y → des ondulations.
  • int(...) arrondit en nombre entier pour choisir la couleur.
▶
→ des vagues douces de couleur.
Étape 5 — l'animation !
On met tout dans une boucle while avec le temps t qui avance : 
import math, time, shutil
cols, rows = shutil.get_terminal_size(); rows -= 1
print("\033[?25l", end="")              # cache le curseur
t = 0
try:
    while True:
        print("\033[H", end="")         # curseur tout en haut
        for y in range(rows):
            ligne = ""
            for x in range(cols):
                v = math.sin(x*0.1+t) + math.sin(y*0.1-t) + math.sin((x+y)*0.08+t)
                couleur = 16 + int((v+3)/6*215)
                ligne += f"\033[48;5;{couleur}m "
            print(ligne + "\033[0m")
        t += 0.2                         # le temps avance -> ca bouge
        time.sleep(0.05)
except KeyboardInterrupt:
    print("\033[0m\033[?25h")            # remontre le curseur
🔍 Ce que fait le code :
  • while True: = boucle sans fin : le cœur de l'animation.
  • \033[H remet le curseur en haut pour redessiner par-dessus → effet animé.
  • t += 0.2 fait avancer le « temps » → les vagues se déplacent ; time.sleep attend entre 2 images.
  • except KeyboardInterrupt = sortir proprement avec Ctrl+C.
▶ python3 plasma.py
(Ctrl+C pour arrêter) → ça bouge ! 🎉
✦ À toi : change les 0.1 et 0.08 de l'étape 5. Chaque nombre donne une animation différente !

🎹 Défi 2 — Fabrique de la musique

On va créer du son avec des maths. Installe d'abord les outils :

pkg install python3-sounddevice python3-numpy

Puis : micro musique.py

Étape 1
Un seul son : une onde sinusoïdale à 440 Hz (la note « la »). 
import numpy as np, sounddevice as sd
SR = 44100                              # qualite du son
duree = 0.5
t = np.linspace(0, duree, int(SR*duree), False)
son = 0.3 * np.sin(2*np.pi*440*t)       # 440 Hz = la note "la"
sd.play(son.astype(np.float32), SR); sd.wait()
print("Tu as entendu un 'la' !")
🔍 Ce que fait le code :
  • np.linspace crée plein de petits instants (les « échantillons » du son).
  • np.sin(2*np.pi*440*t) = une onde à 440 vibrations/seconde = la note « la ».
  • sd.play joue le son, sd.wait attend qu'il finisse.
▶ python3 musique.py
→ tu entends un « la » ! 🔊
Étape 2
On range ça dans une fonction note() et on joue 3 notes : 
import numpy as np, sounddevice as sd
SR = 44100
def note(freq, duree=0.4):              # une fonction qui fabrique une note
    t = np.linspace(0, duree, int(SR*duree), False)
    return 0.3 * np.sin(2*np.pi*freq*t)

  • np.concatenate([...]) met plusieurs notes bout à bout.
  • 262, 330, 392 = les fréquences de do, mi, sol.

import curses
def main(stdscr):
    curses.curs_set(0); stdscr.nodelay(True); stdscr.timeout(60)
    h, w = stdscr.getmaxyx()
    rx, rw = w//2, 8
    bx, by, ddx, ddy = w//2, h-3, 1, -1     # balle : position + direction
    while True:
        k = stdscr.getch()
        if k == ord('q'): break
        if k == curses.KEY_LEFT: rx = max(1, rx-2)
        elif k == curses.KEY_RIGHT: rx = min(w-rw-1, rx+2)
        bx += ddx; by += ddy
        if bx <= 1 or bx >= w-2: ddx = -ddx       # rebond murs gauche/droite
        if by <= 1: ddy = -ddy                    # rebond plafond
        if by == h-2 and rx <= bx <= rx+rw: ddy = -1   # rebond raquette
        if by >= h-1: break                       # balle perdue
        try:
            stdscr.clear(); stdscr.border()
            stdscr.addstr(h-2, rx, "=" * rw)
            stdscr.addch(by, bx, "O")
        except curses.error: pass
        stdscr.refresh()
    stdscr.nodelay(False)
    stdscr.addstr(h//2, max(0, w//2-4), "Perdu !"); stdscr.getch()
curses.wrapper(main)
🔍 Ce que fait le code :
  • bx, by = position de la balle ; ddx, ddy = sa direction.
  • ddx = -ddx inverse la direction quand elle touche un mur → rebond.
  • Sur la raquette elle remonte ; si elle passe en bas → break (perdu).

Étape 3 — les briques
On ajoute les briques [] à casser, le score, et la victoire : 
import curses
def main(stdscr):
    curses.curs_set(0); stdscr.nodelay(True); stdscr.timeout(60)
    h, w = stdscr.getmaxyx()
    briques = set()
    for by in range(2, 5):
        for bx in range(2, w-3, 4): briques.add((by, bx))
    rx, rw = w//2, 8
    bx, by, ddx, ddy = w//2, h-3, 1, -1
    score = 0
    while True:
        k = stdscr.getch()
        if k == ord('q'): break
        if k == curses.KEY_LEFT: rx = max(1, rx-2)
        elif k == curses.KEY_RIGHT: rx = min(w-rw-1, rx+2)
        bx += ddx; by += ddy
        if bx <= 1 or bx >= w-2: ddx = -ddx
        if by <= 1: ddy = -ddy
        if by == h-2 and rx <= bx <= rx+rw: ddy = -1
        if by >= h-1: break
        for cible in ((by, bx), (by, bx-1)):       # brique touchee ?
            if cible in briques:
                briques.discard(cible); ddy = -ddy; score += 1; break
        try:
            stdscr.clear(); stdscr.border()
            stdscr.addstr(0, 2, f" Score: {score}  briques: {len(briques)} (q) ")
            for (yy, xx) in briques: stdscr.addstr(yy, xx, "[]")
            stdscr.addstr(h-2, rx, "=" * rw)
            stdscr.addch(by, bx, "O")
        except curses.error: pass
        if not briques:
            stdscr.addstr(h//2, max(0, w//2-4), "GAGNE !"); stdscr.refresh(); break
        stdscr.refresh()
    stdscr.nodelay(False); stdscr.getch()
curses.wrapper(main)
🔍 Ce que fait le code :
  • briques = un ensemble de positions à casser.
  • Quand la balle touche une brique : on l'enlève (discard), elle rebondit, +1 au score.
  • if not briques: → toutes cassées → gagné !

import curses
def case(g, y, x):
    return g[y][x] if 0 <= y < len(g) and 0 <= x < len(g[0]) else 'X'
def main(stdscr):
    curses.curs_set(0); stdscr.nodelay(True); stdscr.timeout(120)
    g = [list(r) for r in NIVEAU]; py, px = 1, 1
    while True:
        k = stdscr.getch()
        if k == ord('q'): break
        ny, nx = py, px
        if k == curses.KEY_LEFT: nx -= 1
        elif k == curses.KEY_RIGHT: nx += 1
        elif k == curses.KEY_UP: ny -= 1
        elif k == curses.KEY_DOWN: ny += 1
        if case(g, ny, nx) != 'X': py, px = ny, nx     # on ne traverse pas les murs
        try:
            stdscr.clear()
            for y, row in enumerate(g): stdscr.addstr(y, 0, "".join(row))
            stdscr.addch(py, px, '@')
        except curses.error: pass
        stdscr.refresh()
curses.wrapper(main)
🔍 Ce que fait le code :
  • NIVEAU = la carte en lettres (X=mur, H=échelle, $=or, .=vide).
  • case(g,y,x) regarde ce qu'il y a à un endroit (mur en dehors de la carte).
  • On bouge seulement si la case visée n'est pas un mur X.

Étape 2 — gravité, échelles, or
On ajoute la gravité (tu tombes), les échelles (flèche Haut) et l'or :

def case(g, y, x):
    return g[y][x] if 0 <= y < len(g) and 0 <= x < len(g[0]) else 'X'
def main(stdscr):
    curses.curs_set(0); stdscr.nodelay(True); stdscr.timeout(120)
    g = [list(r) for r in NIVEAU]; py, px = 1, 1; score = 0

        if case(g, py+1, px) not in ('X', 'H') and case(g, py, px) != 'H':

        except curses.error: pass
        stdscr.refresh()
        if score >= 4:
            stdscr.addstr(len(g)//2, 5, "GAGNE !"); stdscr.refresh(); stdscr.getch(); break

  • La gravité : s'il n'y a ni sol ni échelle sous les pieds, on tombe (py += 1).
  • La flèche Haut ne marche que sur une échelle H.
  • if g[py][px] == '$' : on ramasse l'or et on le remplace par du vide.

Étape 2 — la magie
On « lisse » avec un automate cellulaire, répété 5 fois → ça creuse des cavernes : 
import random
L, H = 50, 18
grille = [[1 if random.random() < 0.45 else 0 for _ in range(L)] for _ in range(H)]
for _ in range(5):                          # 5 passes de lissage
    neuf = [[0]*L for _ in range(H)]
    for y in range(H):
        for x in range(L):
            murs = sum(
                not (0 <= y+dy < H and 0 <= x+dx < L) or grille[y+dy][x+dx] == 1
                for dy in (-1,0,1) for dx in (-1,0,1))
            neuf[y][x] = 1 if murs >= 5 else 0
    grille = neuf
for ligne in grille:
    print("".join("#" if c else " " for c in ligne))
🔍 Ce que fait le code :
  • Pour chaque case, on compte ses voisines qui sont de la roche.
  • 5 voisines-roche ou plus → la case devient roche, sinon elle devient vide.
  • Répété 5 fois, ça « creuse » de vraies cavernes : c'est un automate cellulaire !

import curses, random
L, H = 50, 18
def generer():
    g = [[1 if random.random() < 0.45 else 0 for _ in range(L)] for _ in range(H)]
    for _ in range(5):
        n = [[0]*L for _ in range(H)]
        for y in range(H):
            for x in range(L):
                murs = sum(not (0 <= y+dy < H and 0 <= x+dx < L) or g[y+dy][x+dx] == 1
                           for dy in (-1,0,1) for dx in (-1,0,1))
                n[y][x] = 1 if murs >= 5 else 0
        g = n
    return g
def main(stdscr):
    curses.curs_set(0); stdscr.nodelay(True); stdscr.timeout(120)
    g = generer()
    py, px = 1, 1
    for y in range(H):                       # trouve une case vide pour demarrer
        for x in range(L):
            if g[y][x] == 0: py, px = y, x; break
        else: continue
        break
    while True:
        k = stdscr.getch()
        if k == ord('q'): break
        ny, nx = py, px
        if k == curses.KEY_UP: ny -= 1
        elif k == curses.KEY_DOWN: ny += 1
        elif k == curses.KEY_LEFT: nx -= 1
        elif k == curses.KEY_RIGHT: nx += 1
        if 0 <= ny < H and 0 <= nx < L and g[ny][nx] == 0:
            py, px = ny, nx
        try:
            stdscr.clear()
            for y, row in enumerate(g):
                stdscr.addstr(y, 0, "".join("#" if c else " " for c in row))
            stdscr.addch(py, px, '@')
            stdscr.addstr(H, 0, "Explore ta grotte !  (q pour quitter)")
        except curses.error: pass
        stdscr.refresh()
curses.wrapper(main)
🔍 Ce que fait le code :

  • On cherche une case vide pour y poser l'explorateur @.
  • On se déplace seulement si la case d'arrivée est vide (pas de la roche).
